СократАИ — ИИ-ассистент для самостоятельной работы студентов
Интерактивная веб-платформа, обучающая через сократический диалог: ИИ не даёт готовых ответов, а помогает студенту самостоятельно прийти к решению с помощью наводящих вопросов.

----

🌟 Особенности

Сократический метод – ассистент направляет студента, развивая критическое мышление.
Чат с ИИ – поддерживает реальные API (OpenAI, Groq, OpenRouter, Together AI) и демо-режим.
Учебные материалы – встроенная база знаний (Python, ООП, SQL, веб-разработка, алгоритмы, матанализ).
Расписание и дедлайны – управление заданиями с приоритетами и отслеживанием просрочек.
Личный кабинет – статистика, экспорт диалогов, очистка истории.
Адаптивный дизайн – тёмная тема, мобильная и десктопная версии.
Без сервера – все данные (пользователь, настройки, сообщения, дедлайны) хранятся в localStorage.

----
🧠 Как это работает

Сократический метод реализован через системный промпт, который запрещает прямые ответы и код. Вместо этого ИИ задаёт вопросы, разбивает задачи на шаги, просит объяснить понятия своими словами – и только направляет к правильному решению.
Пример диалога:
Студент: Напиши код для сортировки списка.
Ассистент: Я не даю готовый код, но давайте разберёмся вместе. Какой алгоритм сортировки вы бы выбрали и почему? Какие данные у вас на входе?

----

🚀 Демо-режим

При первом запуске (без API-ключа) ИИ отвечает шаблонными сократическими фразами. Это позволяет протестировать интерфейс и принципы работы.

----

🛠 Технологии

Frontend: HTML5, CSS3, JavaScript (Vanilla)
Дизайн: CSS-переменные, flexbox/grid, анимации, glassmorphism
API: OpenAI-совместимые провайдеры (OpenAI, Groq, OpenRouter, Together AI, custom)
Хранение: localStorage (пользователь, настройки, чат, дедлайны)

----

📦 Установка и запуск

Клонируйте репозиторий или скачайте файлы.
Убедитесь, что все файлы (index.html, styles.css, app.js) находятся в одной папке.
Откройте index.html в любом современном браузере (Chrome, Firefox, Edge, Safari).
Никаких серверных зависимостей и сборщиков не требуется.

----

🔌 Подключение реального ИИ (API)

Нажмите на иконку ⚙️ в чате (или в настройках профиля).
Выберите провайдера (OpenAI, Groq, OpenRouter, Together AI или Custom).
Введите API-ключ (получить можно по ссылке в интерфейсе).
Выберите модель (например, gpt-3.5-turbo или llama-3.3-70b-versatile).
Нажмите «Проверить», а затем «Сохранить».
API-ключ хранится только в вашем браузере и никуда не передаётся кроме прямых запросов к API.

🧩 Функциональные разделы

Раздел, Описание, Главная,	Приветствие, статистика, ближайшие дедлайны, прогресс, быстрый доступ к материалам.

⚠️ Примечания

Приложение не отправляет данные на сервер – весь код выполняется локально.
В реальном продакшене необходимо шифрование и серверное хранение данных.
Сократический метод вшит в системный промпт – его невозможно обойти через обычные запросы (в демо-режиме также соблюдается философия).
Для работы с некоторыми провайдерами (например, Groq) требуется бесплатный API-ключ.
